🔹 **Factorio — Todo List** is a powerful tool built to help you organize and track your Factorio engineering projects with a persistent in-game todo list. Keep construction goals, research targets, and factory expansion plans organized without leaving the game.

🔸 Whether you're a seasoned professional or just getting started, **Factorio — Todo List** delivers a clean, intuitive experience packed with everything you need — right out of the box. ## 🚀 Features

| **Feature** | **Description** |
|:---|:---|
| **Task Creation** | Add and edit to-do items directly from an in-game GUI |
| **Persistent Storage** | Todo list saves with the game file and loads on the next session |
| **Priority Marks** | Mark tasks as high priority, in progress, or complete |
| **Multiplayer Sharing** | Optional shared todo list visible and editable by all players on a server |
